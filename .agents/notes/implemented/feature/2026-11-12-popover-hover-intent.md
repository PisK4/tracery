# Agent Note: 悬停浮层的触发意图与指针定位

Status: implemented

## Problem

2026-11-11 的单例浮层上线后，扫读链路出现三类可复现的误触。中栏每一行工具行都是锚点，160ms 悬停延迟下正常扫读就会弹出；鼠标离开锚点后 `pointerout` 不清待弹出计时，浮层会在鼠标已经移开的位置补弹；关闭浮层没有冷却，用户想继续看别的 trace 时扫过新锚点又弹，看起来像选错了 trace。位置只按锚点左下角计算，340×380 的浮层直接盖住下面的行与鼠标，想读被盖住的内容只能先移开等 200ms。

左栏会话行整行挂浮层，与「点击选会话」争抢同一个指针动作；浮层出现时 `pointer-events:auto`，点击落在浮层空白上会吞掉选中。

## Decision

### 一、触发按内容分级，离开即取消

轻量读数（组头耗时与 token、路径、轮次、子代理短标）悬停 400ms 弹出；工具参数与结果这类重内容 600ms；键盘 focus 700ms。`pointerout` 无条件 `clearTimeout(showTimer)`，鼠标离开锚点后不再补弹。关闭后 300ms 冷却：冷却期内进入的锚点把计时推迟到冷却结束，停住仍会弹；中途离开照常取消。

### 二、浮层出现在指针旁，不盖住指针

单例位置改为以触发时的指针坐标为基点，右下偏移 14/18px；越界翻到另一侧并 clamp 视口。键盘触发没有有效指针位置，回退到锚点 rect 下缘。浮层宽 340、最高 380 不变。出现后 160ms 淡入并上移 4px；出现初期 120ms 内 `pointer-events:none`，正在进行的点击不会落在刚弹出的浮层上。

### 三、关闭入口补齐

Esc、浮层外 `pointerdown`、页面滚动与窗口 resize 都会立即关闭。浮层自身可悬停保持，移出后 200ms 消失。关闭时内容保留到淡出结束再清空，不出现空壳闪动。

### 四、锚点收窄

中栏工具行的 `data-pop-key` 从整行 button 移到摘要区 `.compact-preview`；工具名 chip、标签与行尾读数不再触发。键盘焦点仍落在整行 button，`focusin` 在 `.compact-select` 内寻找摘要锚点。左栏会话行删除悬停浮层，只保留点击选会话，完整标题由原生 `title` 兜底；`sessionPopHtml` 一并删除。右栏工具 chip 与中栏共用 600ms 重内容延迟，注册表条目由内容闭包改成 `{build, heavy}`。

`+N` 目标清单与 step-pop 重叠时，step-pop 跳过 `[data-more-key]`，避免两个浮层同时出现。

## Alternatives considered

- **整行保留锚点、只加延迟**：延迟能过滤扫读，但行尾读数区与工具名仍会触发，长会话里的误触面没有缩小。收窄到摘要区把「想看参数」的意图与行的点击目标分开。
- **工具参数与结果改点击钉住**：重内容天生适合点击态，但这会与「点击行选中 trace」争抢同一个动作，需要另设入口。本轮先用 600ms 重延迟验证，点击钉住留到观感仍不够时再做。
- **浮层挂进锚点子元素（demo 的纯 CSS 形态）**：鼠标从 chip 移入浮层不会离开锚点，生命周期最稳；长会话 100+ 组头、每组 2 个 chip 的 DOM 增量不可接受，单例注册表的预算理由仍然成立。
- **左栏会话概况搬到会话头**：本轮只删除浮层解除与点击的冲突，概况内容没有搬进会话头；左栏是否还需要概况，等真实使用反馈再定。
- **冷却期内直接丢弃意图**：实现更简单，但用户关闭后立刻移到下一行并停住时不会弹出，需要再动一下鼠标。改为冷却结束继续计时。

## Consequences

注册表条目从函数变成 `{build, heavy}`，新增锚点时要显式标注重内容。`sessionPopHtml` 与会话行的 `sess:` 键删除。单例浮层与锚点没有 DOM 关系的固有问题仍在：行重渲染后 anchor 指向旧元素，浮层会被下一次 pointerout、scroll 或 pointerdown 收起；这一轮用关闭入口与冷却兜住，没有改回锚点内渲染。

收益是扫读时不再连环误弹，浮层不挡鼠标与当前行，左栏选会话不再被浮层拦截。

## Testing

`tests/web.test.ts` 新增 `placePop` 的右下偏移、越界翻转与小视口 clamp 断言；现有浮层内容分派测试不变。合成页面 8770 实测：轻量约 500ms、重内容约 700ms 出现，指针不在浮层内；Esc 与外部点击关闭；冷却内进入停住后弹出，进入即离开不弹；快速扫过多个锚点后不补弹；浮层可悬停。生产页面在合并部署后人工核验。
