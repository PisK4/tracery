# Agent Note: 空状态蜘蛛插画——只在没有选中 trace 时出现

Status: implemented

## Problem

### 空状态与品牌形象脱节

ATC 原有空状态一律是 24px 标记加一句说明：右栏未选择请求、中栏没有已记录的请求、左栏零会话。这些空状态是界面上面积最大、注意力最空的位置，视觉上却是通用占位符，与已经选定的品牌形象（B1 蜘蛛）没有任何关系。空状态没有数据、没有决策、没有状态语义，插画放在这里不会与任何读数抢注意力；一旦离开空状态，任何停留点都会与 trace 行、会话头、顶栏的实际职责重叠，也会与降噪规则冲突。

### 发布面约束

前端静态发布面是 [STATIC_FILES](../../../../src/http.ts) 白名单加 `readFileSync(entry.file, 'utf8')`。它只发白名单里的文本文件，没有二进制路径，也没有 Range 支持。这条能力不能靠再发一个 MP4/GIF 实现：要么加白名单条目与 MIME，要么把图形塞进已有文本文件。后者更小、更快，也不扩大发布面。

### 资产事实与一条更正

B1 形象由用户选定并批准，真实位图资产在设计工作目录（不在本仓库内）。动效源按 B1 重绘完成，几何来自重绘稿 `rail-fix/spider-rail.svg`（剪影 IoU 0.958，见 [web/empty-state.js](../../../../web/empty-state.js) 头注）。实测更正：B1 原图没有腮红，也没有瞳内高光；之前以为的近白像素是背景薄荷 `#B6F9D6` 的边缘反光，重绘未补这两项。

## Decision

只在没有选中 trace 的空态显示一只吊在丝上的 B1 蜘蛛，其余落点全部不做（见下方明确不做）。

- **落点与尺寸**：右栏未选择请求内接 160px，容器内宽 ≤320px 时降 96px（container query）；中栏没有已记录的请求 200px，在列表可视区内水平垂直居中；左栏零会话不做，保留原文案。右栏空态的插画 markup 只在 [web/app.js](../../../../web/app.js) 一处生成。
- **实现**：内联 SMIL SVG（[web/empty-state.js](../../../../web/empty-state.js)），几何只有一份，动效版在静态骨架上补 `animateTransform`；颜色走 `--spider-body`、`--spider-thread`、`--spider-accent` 三个 token，深浅跟随主题。深色身体提亮到 `#2166B0`，对 `--surface` 3.23:1、对 `--canvas` 3.39:1。
- **时序**：空态持续 500ms 仍未被选中才由 `armSpider` 统一 `beginElementAt` 启动；期间被选中则计时随节点离开文档失效，永不启动。钟摆 ±2°/3s、呼吸 4.5s、眨眼 9s，丝与珠用负偏移还原相位差；未启动时渲染的是完整静态首帧。
- **reduced-motion**：`matchMedia` 命中直接渲染静态成品；中途切到 reduce 整体替换为静态版，不用 `animation:none` 冻动效副本。SMIL 不受 CSS 媒体查询约束，这层判断必须在 JS。
- **可访问性**：插画是装饰，`aria-hidden="true"`，说明文字是唯一语义来源；SVG 内部全部是常量标记，不含用户数据。

## 明确不做

以下每项都是不做，不是后续可选：

- **常驻 / 停留点**（右栏正文末尾滚到底、中栏末尾、顶栏、会话头、左栏末尾）：常驻插画会让界面持续变吵；且现有素材只有吊丝加前肢上举，没有丝上的落地坐姿，几何重绘会读成举手抱空气，要成立需要一张真正的坐姿重绘帧。用户已决定不做。
- **顶栏 logo / 应用图标（蜘蛛方案）**：放弃。等比缩到 24px 时眼睛直径只剩约 0.80px，膝折一条腿只有 1–1.3px，不可读；剪影只剩圆身体加八条短腿，B1 的萌没有带过来，用户判定不好看。
- **Trace 行、角色 pill、会话行、失败态、history-loader、正文未到、顶栏存储降级 chip、会话头动作条**：都是承载状态语义的信息位，插画会与读数抢读，与降噪规则冲突；均已判否决。
- **左栏零会话**：250px 栏里 128px 的图占掉一半，标题、搜索框与列表全部失去层级，保留现有空文案。

## Alternatives considered

**位图 / 透明 APNG / GIF。** 被否决不是美术问题，而是发布面问题：白名单只发文本，二进制没有服务路径，也不支持 Range；GIF 还会在深色底上留下抠底光晕。

**CSS keyframes 代替 SMIL。** 与 `prefers-reduced-motion` 的集成更直接，长期支持也更稳。本轮不用，是因为动画源按 SMIL 编写（矢量原型就是 SMIL 时间轴），改成 CSS 等于重写一遍关键帧，且失去单个 SVG 文件可独立打开的性质。若 Safari 风险兑现，CSS 版就是既定退路，而不是临时方案。

**外部 `.svg` 文件 + 白名单条目。** 需要扩 `STATIC_FILES`、加 MIME，并多发一次请求；内联只有一个文件、跟随 `data-theme` 变量，也没有缓存失效问题。否决。

**右栏 200 / 中栏 160 的交换。** 右栏 200 会压到说明文字并挤占读数区，中栏 160 在 544 宽里偏小、镇不住空白。否决。

**左栏也放 128px 插画。** 250px 栏内占比过半，标题、搜索框、列表三层的视觉层级全部塌掉。否决。

**把插画塞进顶栏 logo 或应用图标。** 24px 下眼睛与膝折不可读，只剩生物剪影，品牌辨识度归零。用户已判定不好看。否决。

## Consequences

- 收益：空态承载品牌而不加信息噪音；内联零新增网络请求，`STATIC_FILES` 不扩；几何单份加静态首帧兜底，SMIL 失效时画面仍完整。
- 留观：Safari 对 SMIL 的长期支持是风险，退路是静态首帧与 CSS keyframes 重写，不改落点与尺寸；深色对比余量薄（3.23:1），`--surface`/`--canvas` 微调后必须重测，不达标就继续提亮，不靠阴影或描边冒充；空态长时间停留时循环若被判噪音，降级路径是播完三个循环停在首帧，同一素材无需重绘。
- 验证缺口：尺寸、门控与 reduced-motion 降级没有自动化测试锁定（2026-11-08 核对 tests/ 无 spider 用例），回归靠人工走查；提案阶段的浏览器实测验收项不宣称本轮复测。
